# The Dhaaga Store — Coming Soon

One-page static site for [thedhaagastore.com](https://thedhaagastore.com). Plain HTML + CSS + vanilla JS, no build step.

- Edit toy names/images in the `PRODUCTS` array at the top of `main.js`.
- Custom Order link (WhatsApp) is in `index.html`.
- Hosted on Render as a Static Site; publish directory is the repo root.

Hanging-rail interaction ideas inspired by [interactive-garment-starter](https://github.com/amirmushichge/interactive-garment-starter) (MIT).
